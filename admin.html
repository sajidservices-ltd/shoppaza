Stripe Keys Kahan Se Nikal Kar Lagani Hain? (Step-by-Step Guide)

1. Publishable Key (`pk_live_...`):

Apne Stripe Dashboard mein jayein -> Left side par neechay Developers par click karein -> Phir API keys par click karein. Wahan Publishable key ko copy kar ke upar pehle box mein paste karein.

2. Secret Key (`sk_live_...`):

API keys wale page par hi neechay "Standard keys" mein Secret key ke aagay "Reveal live key" ka button dabayein, key copy karein aur doosre box mein paste karein.
